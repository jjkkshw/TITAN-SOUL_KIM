# Anthropic Prompt Engineering Overview

## 핵심 내용

Anthropic 공식 프롬프트 엔지니어링 가이드 개요 페이지. 프롬프트 엔지니어링 기법의 범주와 언제 적용하는지를 설명. 실제 상세 기법은 "Prompting best practices" 페이지에 있음.

## 주요 인사이트

1. **사전 조건**: 성공 기준 정의 + eval 방법 + 초안 프롬프트 — 이 세 가지 없이 프롬프트 엔지니어링 시작 금지
2. **프롬프트 엔지니어링의 범위**: 지연 시간·비용 같은 문제는 다른 모델 선택으로 해결 — 모든 실패가 프롬프트 문제는 아님
3. **주요 기법 카탈로그**: 명확성·예시, XML 구조화, 역할 프롬프팅, 사고 과정(thinking), 프롬프트 체이닝, zero-shot/few-shot, CoT
