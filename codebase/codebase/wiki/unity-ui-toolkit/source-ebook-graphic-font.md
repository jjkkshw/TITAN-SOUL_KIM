# 소스: Graphic and Font Assets Preparation (E-Book)

## 핵심 내용
Sprite PPU/MeshType 설정, Sprite Atlas vs Dynamic Atlas, FontAsset(SDF) 사용 권장, 에셋 임포트 Best Practices (4K 시작, PSD 워크플로우, AssetPostProcessor).

## 주요 인사이트
- Dynamic Atlas가 런타임 인벤토리 등 동적 UI에 효과적
- FontAsset 사용 시 Font Subsetting으로 메모리 절감
- Sprite Atlas + Dynamic Atlas 병용으로 배칭 효율 극대화
