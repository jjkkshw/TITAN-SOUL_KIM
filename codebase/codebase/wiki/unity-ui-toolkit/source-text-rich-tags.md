# 소스: Rich Text Tags 레퍼런스

## 핵심 내용
UI Toolkit 지원 리치 텍스트 태그 전체 목록: 기본 포맷(b/i/u/s), 색상/투명도, 크기/간격, 정렬, 링크/스프라이트, 폰트 효과, 대소문자 변환, noparse/style.

## 주요 인사이트
- `<link>` 태그와 `PointerUpLinkTagEvent`로 인라인 클릭 콜백 구현
- `<noparse>`로 태그 표시(코드 예시 등) 가능
- Advanced Text Generator(ATG)에서는 일부 태그 제한
