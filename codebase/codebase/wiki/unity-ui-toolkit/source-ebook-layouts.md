# 소스: Layouts (E-Book Chapter)

## 핵심 내용
Yoga(Flexbox) 레이아웃 엔진. flex-direction/wrap, flex-grow/shrink/basis, align-items/justify-content, Relative vs Absolute 위치 모드, Panel Settings Scale Modes.

## 주요 인사이트
- UXML은 프리팹처럼 재사용 가능한 컴포넌트 기반 아키텍처 지원
- Absolute 위치는 팝업/장식/인디케이터에 적합 (형제에 영향 없음)
- 플랫폼 확장성: % 단위 사용
- 애니메이션: width/height 변경 지양 → translate/scale/rotate 사용
