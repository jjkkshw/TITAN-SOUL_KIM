# 소스: Naming Conventions (E-Book Chapter)

## 핵심 내용
BEM(Block Element Modifier) 네이밍 컨벤션. block-name__element-name--modifier-name 구조. Kebab case 필수. 의미론적 이름 권장.

## 주요 인사이트
- Unity 공식 e-book이 BEM 강력 권장
- AddToClassList() 생성자에서 사용 권장
- 멀티 프로젝트: 접두사로 충돌 방지
- 아트 에셋까지 네이밍 컨벤션 확장
