# 소스: UI Builder

## 핵심 내용
StyleSheets/Hierarchy/Library/Viewport/Inspector/Code Preview 6개 패널로 구성된 시각 UXML/USS 편집기. Standard(내장) + Project(커스텀) 탭으로 컴포넌트 라이브러리 구성.

## 주요 인사이트
- [UxmlElement] 커스텀 컨트롤은 Library > Project에 자동 등록
- UXML/USS Preview 패널로 생성 코드 실시간 확인
- 선택 대상에 따라 Inspector 내용 동적 변경
- 테마 드롭다운으로 TSS 미리보기 가능
