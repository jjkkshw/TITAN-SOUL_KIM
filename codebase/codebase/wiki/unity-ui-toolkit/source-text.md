# 소스: Text (E-Book Chapter)

## 핵심 내용
TextCore+SDF. TTF/OTF → Font Asset SDF. ASCII는 512×512/패딩5 충분. 리치 텍스트 태그, 그라디언트, OS 이모지(Dynamic OS 아틀라스), Text Style Sheets.

## 주요 인사이트
- Font Variant로 별도 아틀라스 없이 Face Info 독립 관리
- OS 이모지 방식이 임베드보다 빌드 크기 절약
- Text Style Sheets로 텍스트 많은 앱에서 포맷 중앙화
