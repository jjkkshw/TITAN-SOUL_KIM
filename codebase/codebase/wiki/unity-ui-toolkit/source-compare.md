# 소스: Comparison of UI systems in Unity

## 핵심 내용
Unity 6.3 기준 UI Toolkit vs uGUI vs IMGUI 비교. Runtime은 uGUI 권장, Editor는 UI Toolkit 권장. UI Toolkit은 데이터 바인딩·SVG·RTL 등 모던 기능 강점.

## 주요 인사이트
- UI Toolkit은 최종적으로 권장 시스템이 될 예정이나 현재는 uGUI 기능 일부 부족
- 디자이너에게는 UI Toolkit의 document-based approach + UI Builder가 유리
- IMGUI는 경량·빠른 에디터 UI에 여전히 유효
- uGUI는 In-scene authoring, 직렬화된 이벤트 필요 시 우위
