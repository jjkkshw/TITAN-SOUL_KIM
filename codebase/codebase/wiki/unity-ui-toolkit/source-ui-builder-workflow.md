# 소스: UI Builder 워크플로우 & Debugger

## 핵심 내용
UI Builder 6단계 워크플로우(계층 구성→스타일→USS 추출→저장). Debugger Pick Element로 런타임 요소 선택. Live Reload로 수정 즉시 반영.

## 주요 인사이트
- 색상 알파 기본값 0 → 배경색 안 보일 때 확인
- Debugger 스타일 수정은 임시 (재생성 시 사라짐)
- "Extract Inlined Styles" 기능으로 인라인→USS 자동 변환
