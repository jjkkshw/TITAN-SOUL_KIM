# 소스: UXML Elements Reference

## 핵심 내용
UI Toolkit 내장 컨트롤 전체 목록: 기본 요소, 입력 필드, 벡터 필드, 선택 컨트롤, 슬라이더, 컨테이너, 목록/트리, 탭, Editor 전용(ColorField/CurveField/ObjectField 등), 툴바.

## 주요 인사이트
- `PropertyField`가 Inspector 스타일 자동 UI 생성에 가장 효율적
- `ListView`는 가상화(아이템 재활용)를 내장
- 대부분의 요소가 Runtime + Editor 모두 사용 가능 (Editor 전용 명시 제외)
