# 소스: Introduction to UI Toolkit

## 핵심 내용
UI Toolkit은 웹 기반 설계 원칙(UXML/USS/C# = HTML/CSS/JS)으로 Unity UI를 개발하는 retained-mode 프레임워크. UI Builder·UI Debugger·Sample Library가 핵심 도구.

## 주요 인사이트
- Retained mode: visual tree 메모리 유지, 자동 렌더링
- Flexbox 레이아웃으로 반응형 디자인 용이
- UXML/USS가 C# 방식보다 권장 (분리·재사용성)
- 팀 역할 분배: 디자이너(UI Builder), 개발자(C#), 아티스트(성능)
