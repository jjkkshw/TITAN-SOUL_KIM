# 소스: USS Selectors 레퍼런스

## 핵심 내용
9가지 셀렉터 타입(Type/Name/Class/Universal/Descendant/Child/Multiple/List/Pseudo-class) 전체 문법과 예시. Specificity 우선순위 규칙. 성능 가이드라인.

## 주요 인사이트
- Child 셀렉터(`>`)가 Descendant(공백)보다 성능 좋음
- `:hover`가 가장 비싼 의사 클래스 (마우스 이동마다 계층 재스타일링)
- BEM 단일 클래스 셀렉터가 가장 빠른 매칭
