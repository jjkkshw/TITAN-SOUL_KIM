# 소스: Events Reference

## 핵심 내용
Pointer/Change/Click/Keyboard/Focus/Layout/Drag-Drop/Transition/Panel/Navigation 이벤트 타입 요약. 각 타입의 발생 시점과 주요 프로퍼티.

## 주요 인사이트
- Pointer Events가 Mouse Events보다 먼저 발생
- `GeometryChangedEvent`로 레이아웃 완료 후 크기 읽기
- `AttachToPanelEvent` / `DetachFromPanelEvent`로 초기화/정리 패턴
- `TransitionEndEvent`로 애니메이션 완료 콜백
