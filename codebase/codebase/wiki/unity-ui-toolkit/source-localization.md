# 소스: Localization (E-Book Chapter)

## 핵심 내용
Unity 6 Localization 패키지와 UI Toolkit 직접 통합. String Tables(텍스트)/Asset Tables(에셋), UI Builder 바인딩, SelectedLocale API, Smart Strings, Google Sheets/CSV 연동.

## 주요 인사이트
- FlexBox 자동 크기 조정으로 언어별 텍스트 길이 차이 수용
- StringChanged 이벤트로 번역 내용 후처리 가능
- Dragon Crashers 샘플이 실사용 구현 참고
