# UI Toolkit (Main Landing Page)

## Core Definition
"UI Toolkit is a collection of features, resources, and tools for developing user interface (UI)."

## Key Capabilities

- **Visual Development**: UI Builder — UXML/USS 에셋 그래픽 편집 인터페이스
- **Structural Foundation**: UXML 마크업 또는 C# 코드로 UI 구성
- **Styling System**: USS (Unity StyleSheets)로 시각적 표현 처리
- **Interactivity**: 사용자 입력, 포인터 인터랙션, 드래그앤드롭 이벤트 시스템
- **Rendering**: Unity 그래픽 레이어 위에 구축된 커스텀 렌더링 시스템
- **Data Integration**: 데이터 바인딩으로 프로퍼티와 UI 컨트롤 연결
- **Specialized Components**: Editor UI 및 Runtime UI를 위한 별도 컴포넌트 세트
- **Typography**: 폰트 및 스타일링을 포함한 포괄적 텍스트 처리
- **Quality Assurance**: 테스팅 및 디버깅 도구

## Target Audiences
신규 사용자와 숙련 개발자 모두 지원. uGUI 또는 IMGUI에서 이주하는 팀을 위한 마이그레이션 가이드 포함.
